# timestamp / 时间戳转换器

一款基于 [uTools](https://u.tools) 的时间戳转换插件（同时兼容纯浏览器直接打开）。支持秒 / 毫秒 / 微秒 / 纳秒四种精度的时间戳与日期时间的双向实时转换，内置完整 IANA 时区库与历史偏移换算、自定义时区、智能日期识别、日历与滚轮时间选择，并提供中英文双语界面。

纯原生 HTML / CSS / JavaScript，无第三方依赖、无构建步骤，可直接作为 uTools 插件目录使用。

## 功能特性

### 双向实时转换
- **日期 → 时间戳**：输入日期时间（如 `2026-09-07 13:49:08`）实时换算为秒 / 毫秒 / 微秒 / 纳秒时间戳，精度与顶部 Tab 联动，点击结果即复制。
- **时间戳 → 日期**：自动按位数识别秒（10 位）/ 毫秒（13 位）/ 微秒（16 位）/ 纳秒（19 位）并切换到对应精度，内部以 `BigInt` 处理超大值，结果按当前时区显示，支持悬停查看/复制多种日期格式。
- **精度 Tab**：秒 / 毫秒 / 微秒 / 纳秒四档切换，输入提示、结果区、当前时间面板同步联动。

### 智能日期解析
- 内置 ISO 8601（含 `T`、`Z`、`±HH:mm` 时区后缀）、`YYYY-MM-DD` / `YYYY/MM/DD`、中文年月日、RFC 2822 / 英文月份（`Thu, 07 Sep 2026`）、月/日式等解析器，可分别启停。
- 相对日期：`今天`、`昨天`、`明天`、`today`、`yesterday`、`tomorrow` 等。
- 快捷建议：输入部分日期（如 `2026-08`、`2025`）时实时列出候选日期。
- 月/日式日期按「美国 / 欧洲」歧义风格解析，可在日期解析设置中切换。
- **自定义解析规则**：支持占位符格式（`YYYY-MM-DD`）或命名分组正则，自由扩展。

### 多时区支持
- 内置常用时区 + 完整 IANA 时区库，输入时区与展示时区可独立设置，卡片标题实时显示城市与 UTC 偏移芯片。
- **时区偏移精确到历史**：基于 `Intl.DateTimeFormat` 计算，正确处理夏令时、1901 年前的 LMT 秒分量（如上海 `+08:05:43`）乃至公元前的年份；对缺失历史数据的引擎提供内置回退表。
- **自定义时区**：中文 / 英文名 + UTC 偏移（`+08:00`、`+8`、`8`），可选别名与真实 IANA 时区（如 `America/New_York`，自动跟随夏令时）。
- **可视化时区选择器**：时区配置弹窗内支持搜索 / 全部 / 已选中 / 未选中筛选，并可用双滚轮选择器直观选取城市与偏移；点击任意卡片标题的偏移芯片即可快速弹出。
- 时区定制完整入库 / 内存会话覆盖两级生效。

### 日期格式与复制
- Token 格式化：`YYYY` `YY` `MM` `DD` `HH`(24h) `hh`(12h) `mm` `ss` `SSS` `A/a` `W`(中文星期) `WD`(英文星期) `Z`(时区偏移)。
- 内置 ISO / 斜杠 / 中文完整 / 中文带星期 / 含毫秒等预设，支持自定义格式（含别名），时间戳结果悬停即可在多格式列表中一键复制。

### 实时当前时间
- 每秒刷新本地时间与各级时间戳（内部 50ms 平滑更新），支持暂停 / 继续，点击即复制。
- 微秒 / 纳秒末位可配置为「与毫秒推算一致」或「随机」。
- 当前时区卡片标题点击可直接展开时区选择。

### 日历组件
- 日 / 月 / 年三级视图，支持年份快速跳转输入。
- 时分秒 / 毫秒 / 微秒 / 纳秒滚轮选择，`此刻` / `确定` 快速落点。

### 系统设置
- 默认选项卡、各级精度是否显示、主题（跟随系统 / 深色 / 浅色）、微秒纳秒显示模式，均可一键重置。

### 输入体验与快捷键
- **粘贴自动清洗**：时间戳输入框仅接受数字与开头负号，粘贴时自动剥离千分位逗号、空白等噪声（`1,754,003,672` → `1754003672`）；日期 / 时间输入框自动剥离数字间的千分位逗号与零宽字符，且不影响 RFC 2822 英文日期。
- **ESC 逐级回退**：依次关闭当前最内层弹层（搜索建议 → 日历 → 时区弹层 → 配置弹窗），主页无弹层时回到 uTools 输入框。
- 中英文一键切换。

## 快速开始

### 作为 uTools 插件
1. 打开 uTools，点击「插件中心」，选择「打开插件目录」，将本项目目录放入。
2. 搜索 `时间戳`、`timestamp` 或输入 `ts` 唤起。
3. 支持**文本正则匹配**：选中 10/13/16/19 位数字（秒 / 毫秒 / 微秒 / 纳秒级）自动识别并转换；选中日期字符串（如 `2026-09-07`）自动填充为时间戳。
4. 启动时自动读取剪贴板中的时间戳或日期字符串并预填。

### 浏览器直接使用
无需安装，直接打开 `index.html` 即可体验全部功能；非 uTools 环境下复制功能回退到浏览器剪贴板 API。

## 使用说明

1. **日期 → 时间戳**：左侧输入日期（`2026-09-07`、`2026年9月7日 13时49分08秒`）或相对 / 部分日期，从快捷建议中选择，点击结果复制。
2. **时间戳 → 日期**：右侧粘贴时间戳，自动按位数切换精度，结果按当前时区显示；悬停结果查看多格式列表并复制。
3. **时区切换**：顶部选择展示时区；带 `Z`、`±HH:mm` 等时区信息的日期字符串会被自动识别；点击卡片标题偏移芯片可快速调整。
4. **实时时间**：底部当前时间面板支持暂停刷新，方便对照记录。
5. **配置**：右上角 ⚙️ 打开配置弹窗，可管理时区列表、日期格式、日期解析规则与系统设置。

## 技术实现

- 模块化拆分，按固定顺序加载（见 `index.html`）：`constants → timezones → i18n → validators → error-handler → core → datetime → fields → calendar → convert → tzselector → events`。
- 时区偏移：优先 `Intl.DateTimeFormat` 精确计算（含 LMT 秒分量与公元前年份，采用「瞬时域候选年」而非 era 字段解析规避引擎差异）；引擎缺失历史数据时回退内置 `HISTORICAL_OFFSETS` 表。
- 时间戳范围校验覆盖 ECMAScript 可表示范围（±8.64e15 ms），超出予以提示；超大值经 `BigInt` 无损换算。
- 工程化：`npm run verify` 一键执行语法校验、HTML/i18n 一致性检查、模块加载测试与单元测试。

## 目录结构

```
timestamp/
├── index.html          # 主界面
├── index.css           # 界面样式
├── preload.js          # uTools 预加载脚本
├── plugin.json         # uTools 插件配置（关键词 / 正则匹配 / 高度）
├── logo.png            # 插件图标
├── package.json        # 工程化脚本（校验 / 测试）
├── js/
│   ├── core.js         # 基础工具、系统设置、时区配置 UI、输入清洗
│   ├── datetime.js     # 时间/时区格式化、日期解析引擎、时区历史偏移
│   ├── fields.js       # 日期字段装配、时间戳反推
│   ├── calendar.js     # 日历与滚轮时间选择
│   ├── convert.js      # 转换渲染、格式 token、配置弹窗逻辑
│   ├── tzselector.js   # 时区选择器、时区芯片、i18n 应用
│   ├── events.js       # 事件绑定、ESC 分发、滚动条
│   ├── i18n.js         # 中英文文案
│   ├── data/timezones.js   # IANA 时区数据与别名
│   └── utils/          # constants、validators、error-handler
└── dev/
    ├── scripts/        # validate.mjs、load-test.mjs
    └── tests/          # 单元测试（node:test）
```

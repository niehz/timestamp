# timestamp

一款基于 [uTools](https://u.tools) 的时间戳转换工具，支持秒级 / 毫秒级双向转换、多时区解析、实时时间展示、日历选择与智能日期识别，内置中英文双语界面。

## 功能特性

### 双向转换
- **日期 → 时间戳**：输入日期时间，实时转换为秒级 / 毫秒级时间戳
- **时间戳 → 日期**：输入 10 位秒级或 13 位毫秒级时间戳，实时解析为日期时间
- 输入即转换，无需点击按钮；点击结果可一键复制

### 秒级 / 毫秒级切换
- 顶部 Tab 一键切换秒级（10 位）与毫秒级（13 位）模式，转换结果与输入提示随之联动

### 时区支持
- 内置 21 个常用时区（本地、UTC、北京、东京、纽约、伦敦等），可随时切换
- 输出结果按所选时区展示，并附带当前偏移量（如 `UTC+08:00`）
- 输入时区与输出时区独立设置：日期可指定按某时区解析
- 支持解析带时区信息的日期字符串：`Z`、`UTC`、`GMT`、`±HH:mm` 偏移、RFC 缩写等

### 实时当前时间
- 实时显示本地时间、秒级时间戳、毫秒级时间戳，每秒自动刷新
- 支持暂停 / 继续，方便抄录固定时刻
- 点击任意项即可复制

### 日历组件
- 支持日 / 月 / 年三种视图，点击标题可逐级切换
- 年份输入框实时跟随，支持 `2025`、`2025-08`、`2025-08-31` 等格式并快速跳转
- 时、分、秒、毫秒滚轮选择器，支持滚轮 / 点击，毫秒仅在毫秒级模式显示
- 「此刻」按钮一键取当前时间，「确定」应用选择结果

### 智能日期解析
- 支持多种分隔符：`-`、`/`、中文 `年 / 月 / 日`
- 支持相对日期快捷输入：`今天`、`昨天`、`明天`、`后天` 及英文 `today`、`yesterday`、`tomorrow`
- 支持缺省输入：`2025`（默认当月当日）、`2025-08`（默认当月 1 日）
- 输入过程中弹出快捷建议列表，点选即填入

### 双语界面
- 内置中英文界面，右上角按钮一键切换

### uTools 集成
- 关键词唤起：`时间戳`、`时间戳转换`、`timestamp`、`ts`
- 正则匹配自动识别：
  - 选中 10 位数字 → 秒级时间戳 → 自动转为日期
  - 选中 13 位数字 → 毫秒级时间戳 → 自动转为日期
  - 选中日期字符串 → 自动填充到日期输入框
- 插件启动时自动读取剪贴板中的时间戳
- 按 `Esc` 退出插件

## 使用方式

### uTools 插件安装（本地开发）
1. 打开 uTools，点击输入框左侧的「插件中心」
2. 选择「打开插件目录」
3. 将本项目整个目录拷贝到插件目录下（或直接在 uTools 中导入 `plugin.json`）
4. 重启或搜索关键词 `时间戳` / `timestamp` 即可唤起

### 普通网页使用
直接用浏览器打开 `index.html` 即可体验全部功能（复制功能在非 uTools 环境会退回浏览器剪贴板 API）。

## 技术说明

- 纯原生 HTML / CSS / JavaScript 实现，无任何第三方依赖
- 时区换算基于 `Intl.DateTimeFormat`，支持历史与时区规则变化
- 时间戳支持范围符合 ECMAScript 规范（±8.64e15 毫秒），超出范围给出提示

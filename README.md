# timestamp

一款基于 [uTools](https://u.tools) 的时间戳转换工具。支持秒级 / 毫秒级时间戳与日期时间的双向转换，内置多时区换算、实时当前时间、日历与滚轮时间选择、智能日期识别，并提供中英文双语界面。

## 功能特性

| 模块 | 说明 |
| ---- | ---- |
| 日期 → 时间戳 | 输入日期时间实时换算，输出秒级或毫秒级时间戳 |
| 时间戳 → 日期 | 输入 10 位秒级 / 13 位毫秒级时间戳实时还原为日期时间 |
| 秒 / 毫秒切换 | 顶部 Tab 切换两种精度模式，输入提示、结果、当前时间面板联动 |
| 多时区支持 | 内置本地、UTC 及北京、东京、纽约、伦敦等 21 个时区；输入与输出时区可独立设置，自动显示偏移量 |
| 实时当前时间 | 每秒刷新本地时间、秒级 / 毫秒级时间戳，支持暂停 / 继续与点击复制 |
| 日历组件 | 日 / 月 / 年三级视图，支持年份快速跳转、时间滚轮选择、此刻 / 确定 |
| 智能日期解析 | 兼容 `-`、`/`、中文年月日及 `今天 / 昨天 / 明天 / today / yesterday` 等相对日期 |
| 双语界面 | 中英文一键切换 |

## 快速开始

### 作为 uTools 插件

1. 打开 uTools，唤出输入框并点击右侧「插件中心」
2. 选择「打开插件目录」，将本项目目录放入
3. 搜索 `时间戳`、`timestamp` 或输入 `ts` 唤起

插件支持文本正则匹配：选中 10 位数字（秒级）或 13 位数字（毫秒级）即可直接转换为日期，选中日期字符串则自动填充为时间戳换算。启动时会自动读取剪贴板中的时间戳。

### 浏览器直接使用

无需安装，直接用浏览器打开 `index.html` 即可体验全部功能（非 uTools 环境下复制功能回退到浏览器剪贴板 API）。

## 使用说明

1. **日期 → 时间戳**：在左侧输入日期（如 `2025-08-31`），或输入相对日期 / 部分日期（如 `今天`、`2025-08`）并从快捷建议中选择，点击结果即可复制。
2. **时间戳 → 日期**：在右侧输入框粘贴时间戳，结果按当前时区显示，点击结果复制。
3. **时区切换**：顶部分别选择「输入时区」（解析日期所用）与展示时区；带 `Z`、`±HH:mm` 等时区信息的日期字符串会被自动识别。
4. **实时时间**：底部实时面板可暂停刷新，方便记录当前时刻。

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无第三方依赖
- 时区换算基于 `Intl.DateTimeFormat`，正确处理夏令时等时区规则
- 时间戳覆盖 ECMAScript 可表示范围（±8.64e15 毫秒），超出范围给出提示

# v1.0.4 正式版

- **小数秒分组显示**：毫秒/微秒/纳秒小数位按 3 位一组空格分组（毫秒 3 位 + 微秒 3 位 + 纳秒 3 位，如 `12345` → `123 45`），位数更易读；点击复制自动剥离空格，粘贴自动净化为纯数字
- **低精度导航找回**：在低精度页（毫秒/微秒/纳秒降级）编辑小数秒不再丢位数，切回高精度页且在未手动修改时自动恢复完整精度；多级精度切换与 ESC 导航全程保留最长值；清空/剪切同步失效缓存
- **分组光标修正**：分组空格下光标按数字边界映射、粘贴位置不再错位
- **精度显示 UI**：秒级 TAB 的 ms/us/ns 徽标正确显示「秒」；当前精度受限时的降级 TAB 悬停提示气泡（自适应窗口边缘不溢出）；精度=秒时 ms/us/ns 布局修正
- **微秒输入加宽**：微秒级小数输入框加宽，6 位小数 + 分组空格不再被遮挡
- **质量**：全量验收通过（151 项单元测试全绿）

完整能力详见 `store/README.md` 应用介绍。

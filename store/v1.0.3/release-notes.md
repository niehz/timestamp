## 版本说明
时间戳与日期双向转换工具，唤起即用、输入即转换、点击即复制。（首次发布）

■ 四档精度互转
秒 / 毫秒 / 微秒 / 纳秒级时间戳任意互转，按位数自动识别并切换精度；
超大数值用 BigInt 无损换算，绝无精度损失。

■ 真实时区换算
内置全球 IANA 时区库，精确计算历史时区偏移——正确处理夏令时、
1901 年前的地方平均时（如上海 +08:05:43）、乃至公元前年份；
支持自定义固定偏移 / 别名 / 绑定真实时区（自动跟随夏令时）；
多时区下拉列表自定义勾选，一键切换。

■ 智能日期解析
ISO 8601、RFC 2822、中文年月日、英文日期、相对日期（今天/明天/昨天）、
部分日期实时补全建议；美式/欧式月日歧义可切换；
支持自定义占位符格式（YYYY-MM-DD）或正则解析规则。

■ 夏令时兜底
秋季回退重叠的一小时展示全部候选瞬时；春季跳空的不存在时间明确提示。

■ 日历 · 农历 · 节假日
日/月/年三级视图 + 时分秒/毫秒滚轮选择；
内置农历（1900–2100）与公历/农历节日；
2024–2026 法定节假日与调休班一目了然：橙色"休"、红色"班"角标示人。

■ 全场景顺手
uTools 中选中 10/13/16/19 位数字或日期字符串即自动转换；
启动时自动读取剪贴板预填；粘贴自动剥离千分位与噪声字符；
ESC 逐层关闭弹层；中英文一键切换；跟随系统/黑夜/白天三态主题；
当前时间实时刷新可暂停对照，悬停结果多格式一键复制。
